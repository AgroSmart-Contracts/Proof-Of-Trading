# v0.2 offering contract: test plan (written before the event)

Maps brief 2 §3 to concrete setups and exact assertions. Values come from `v0.2-design.md`.

## Shared fixture (`fn setup() -> T`)
- `Env::default()`, `env.mock_all_auths()`; `env.ledger().set_timestamp(1_000)`.
- `admin`, `treasury`, `investor_a`, `investor_b`, `stranger` = `Address::generate`.
- TUSDC: `register_stellar_asset_contract_v2(tusdc_issuer)`; mint 100,000 to A and B and 200,000 to treasury.
- Share SAC: `register_stellar_asset_contract_v2(share_issuer)`, then `issuer().set_flag(Required | Revocable | ClawbackEnabled)` (same as the spike test), then `set_admin(contract)`.
- Contract: `env.register(Offering, (admin.clone(),))`.
- `params(cap_usd, apy_bps, term_days)` helper: `unit_price = 10_000_000`, `cap_shares = cap_usd * 1e7`, `deadline = now + 7_200`.
- `approve(A)`, `approve(B)` in tests that need them.
- Helper `usd(n: i128) -> i128 { n * 10_000_000 }`.

## Test 11: auth matrix
Positive (the canonical Soroban pattern): after a call under `mock_all_auths`, assert
`env.auths()[0].0 == expected_signer` for the function.

| Fn | Expected signer |
|---|---|
| `create_offering`, `approve_investor`, `fund`, `start_refunds`, `sweep_surplus` | `admin` |
| `deposit_distribution` | `treasury` (stored in the offering, **not** a parameter) |
| `subscribe`, `refund`, `redeem` | `investor` |

Negative: `env.mock_auths(&[MockAuth { address: &stranger, invoke: &MockAuthInvoke { contract: &id, fn_name: "fund", args: (1u32,).into_val(&env), sub_invokes: &[] } }])`, then `try_fund(&1)` is Err. One negative case each for an admin function and for `deposit_distribution` is enough.

## Revert-and-check (do once per key test)
Following TruMarket's testing discipline: temporarily break the implementation with the **Edit** tool (never `sed`), confirm the test fails, and restore. Priority: test 3 (remove the trustline-auth dependency, e.g. call `set_authorized(true)` inside `subscribe`), test 8 (drop the `min()`), test 10 (skip the redeemed flag).
